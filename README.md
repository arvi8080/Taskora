# 🚀 ExpertService - Next-Gen AI-Powered Home Service Marketplace

[![Live Demo](https://img.shields.io/badge/Live_Demo-taskora--brown.vercel.app-2563EB?style=for-the-badge&logo=vercel)](https://taskora-brown.vercel.app)

[![GitHub Repository](https://img.shields.io/badge/GitHub-arvi8080%2FTaskora-10B981?style=for-the-badge&logo=github)](https://github.com/arvi8080/Taskora)

ExpertService (Taskora) is a modern, AI-powered on-demand home service marketplace inspired by Stripe, Linear, Vercel, and Framer design systems. It instantly connects homeowners with background-verified professionals for plumbing, electrical, AC repair, cleaning, painting, carpentry, appliance repair, and emergency SOS dispatches with real-time GPS tracking.

## 🛠️ Technology Stack

React, Node.js, Express.js, MongoDB, Mongoose, Tailwind CSS, Framer Motion, Lucide React, Axios, Socket.io, JWT, Vercel, Render

### **Detailed Architecture**
- **Frontend**: React 18, Tailwind CSS, Framer Motion, Lucide React icons, Axios, React Router DOM, Socket.io-client.
- **Backend**: Node.js, Express.js, MongoDB (Mongoose ODM), WebSockets (Socket.io), JWT Auth, Bcrypt.
- **Deployment**: Vercel (Frontend SPA & Proxy rewrites), Render (Backend Node API service).

## ✨ Key Features

### 🤖 1. AI-Powered Matching & Voice Assistant
- Natural language problem analysis with real-time expert matching.
- AI voice booking simulation supporting regional language requests.

### 📍 2. Real-Time GPS Tracking & Live ETA
- Interactive live tracking showing technician movement en route to home.

### 🚨 3. Emergency SOS Dispatch
- 1-Tap high-priority emergency broadcast for urgent home breakdowns.

### 🎨 4. Premium Modern SaaS UI
- Clean, minimal, glassmorphic floating cards, smooth Framer Motion animations, and dark mode toggle.

### 🛡️ 5. Verified Experts & 30-Day Warranty
- Criminal background-verified professionals backed by a 30-day service warranty.

## 💻 Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/arvi8080/Taskora.git
cd Taskora
```

### 2. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 3. Frontend Setup
```bash
cd ../frontend
npm install
npm start
```
